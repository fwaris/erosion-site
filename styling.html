    Layout and styling¶

    Strata starter style¶

    Use strata_screen for Chalk and Basalt. All five sample apps use this builder. Tap the half-filled circle (the Theme button) in the navigation header to select System, Chalk, or Basalt. System follows the device appearance. Each sample remembers its own choice across launches.

    use erosion_ui::widgets::{button, field, strata_screen};

let page = strata_screen(1, "Field note", vec![
    field("title", "Note title", ""),
    button("save", "Save note"),
]);

    Chalk pairs a warm paper background with oxide actions. Basalt pairs charcoal green with copper actions. Both use sage for enabled switches, 48-unit minimum button heights, 12-unit button corners, and 16-unit default card corners. Explicit corner radii take precedence. Select Change accent on the Controls Gallery home screen to try the alternate patina accent.

    Surfaces, corners, and shadows¶

    Import ViewModifiers to style a keyed node. This example groups a native text field and button inside a padded, elevated surface.

    use erosion_ui::{
    design::Elevation,
    widgets::{button, column, field, ViewModifiers},
};

let form = column("form", vec![
    field("title", "Title", ""),
    button("save", "Save").rounded(16),
]).surface().padding(16).rounded(20).elevation(Elevation::Medium);

    Elevation maps to Android view elevation and UIKit layer shadows. Use Role::Title, Secondary, Accent, and Error to distinguish text by purpose. Pass a theme into the screen builder:

    use erosion_ui::widgets::theme;
let palette = theme("#F7F0E4", "#75461E", "#251D19", "#FAC08C");

    The arguments are light background, light accent, dark background, and dark accent.

    Scrolling, wrapping, and rotation¶

    Use column or row for a stack, scroll for a vertically scrollable viewport, and flow to wrap children to available width. For example, flow("actions", 8, buttons) uses a gap of eight logical units between items and lines. A native list handles row reuse.

    For structural changes, handle HostEvent::WindowResized { width } and store WidthClass::from_width(width). The wide class starts at 600 dp or points. Gallery’s Layout exhibit switches the same three panels from a column to a row. Its wrap example sets Style::flow_item_width to 88 logical units.

    Widget motion¶

    Rust declares target values on a stable key. The host animates between targets using the device display clock. In a view! child block, for example:

    text("card", "Current score", Role::Accent)
    .scale(if model.expanded { 1.1 } else { 1.0 })
    .rotation(if model.expanded { 3.0 } else { 0.0 })
    .motion(Motion { duration_ms: 180, easing: Easing::EaseOut })
    .feedback(model.score_event, Feedback::Pulse);

    Import the motion types from erosion_ui::design and the ViewModifiers trait from erosion_ui::widgets. Translation uses logical units, rotation uses degrees, and scale is uniform about the center.

    • Property change. Set opacity, horizontal or vertical translation, scale, or rotation with a duration and easing. A new widget starts at its declared target.
    • Conditional content. Attach .presence(Presence { enter: Some(PresenceEffect::FadeSlide), exit: Some(PresenceEffect::Fade) }) to the conditional child. Each side can be omitted. Removal immediately drops its input bindings. Eligible visuals finish a 180 ms exit.
    • Layout change. Attach .animate_layout(Motion { duration_ms: 180, easing: Easing::EaseOut }) to a row, column, or flow. Give each child a stable key so it can move and retain focus across reordering. Native scrolling lists handle row movement separately.
    • One-shot feedback. Change the event ID to replay a 240 ms pulse or shake on an existing widget. Keep the ID stable across unrelated renders. Update the score or validation result when the event arrives, independently of animation completion.

    Controls Gallery’s Motion & navigation exhibit demonstrates all four. Reduced motion on iOS and disabled animators on Android apply the final state directly.
