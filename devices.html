    Using device capabilities from Rust¶

    Controls Gallery → Device utilities exercises clipboard, Keychain/Keystore, authentication and haptics with disposable sample data. Erosion delivers pending capability results to the app across page changes.

    Enable capabilities in a framework sample¶

    Use a small .xcconfig under ios/config named for the capitalized Android Gradle module (for example, gallery → Gallery.xcconfig). The Gradle build reads the same simple NAME = value declarations as Xcode. Set the iOS target's Debug and Release config files to this file, apply the DeviceCapabilities XcodeGen template and expose MRustCapabilities and the applicable usage-description settings in the target Info properties, as in Gallery and Field Catch. The standalone counter has its own Gradle and XcodeGen projects. When adding a capability there, use the sample manifest, usage descriptions, and platform dependencies for that feature as a reference. Once the host supports it, another Rust screen in the same app can use it too.

    Setting Meaning
    MRUST_CAPABILITIES Space-separated entries from files photos camera share audio location maps secure biometrics clipboard haptic rtc tilt. An absent declaration enables none.
    MRUST_CAMERA_USAGE, MRUST_MIC_USAGE, MRUST_LOCATION_USAGE, MRUST_FACE_USAGE User-facing purpose strings. Use the Face ID string for protected secrets as well as standalone authentication.
    MRUST_MAP_STYLE MapLibre style filename in the app assets or an HTTPS style URL. The MapLibre build loads worldwide vector tiles and labels from OpenFreeMap as the camera moves. Uncached regions need internet access. The bundled offline map covers central San Francisco with 4,827 active street segments from San Francisco Public Works. Street geometry is distributed under the Open Data Commons Public Domain Dedication and License. DataSF source. Supply licensed tiles and attribution for a production basemap.

    Gradle merges permissions for enabled capabilities and installs a private FileProvider for the camera and share sheet. Android map-enabled samples use MapLibre by default. Field Catch can select Google Maps at build time when the build machine has a key in ~/.config/erosion/android_map_key.txt. iOS uses system MapKit. A map of saved pins works with location access denied. Device permission prompts occur when the user invokes the feature.

    Issue requests¶

    Keep an increasing request ID in the app model. Push an Effect::Capability { id, request } into the app's effects queue and handle HostEvent::CapabilityResult { id, outcome } in DeclarativeApp::on_host_event. Compare the ID with the operation you are expecting. Store the ID with its owning model data until completion or abandonment. Cancel with Effect::CancelCapability { id }. Camera, picker, and share UI can move the app out of the foreground while an operation is pending.

    Task Rust request or control
    Capture or choose a photo Operation::CapturePhoto, Operation::PickPhoto; display the returned asset with asset.image("Photo").key("preview").
    Import, export, share Operation::ImportDocument, Operation::Export { asset }, Operation::Share { text, assets }. Android reports Presented when it opens the chooser. UIKit reports completion or cancellation when the sheet closes.
    Record a memo Operation::Record emits Recording. Issue StopRecording or DiscardRecording with its own ID. The original request receives the final asset or cancellation.
    Play a memo Operation::PlayAudio { asset }, PauseAudio, ResumeAudio, SeekAudio { millis }. The original play request receives progress with position and duration in milliseconds, then a terminal result. Cancel it to release the player.
    Get location Operation::Locate { watch: false } returns one Fix. With watch: true it emits fixes until canceled or backgrounded. Each includes coordinates, timestamp, accuracy in meters, and reduced-accuracy status.
    Display a map map("field", Map { center, zoom: 13.0, recenter: 0, pins, overlays }) takes its map data from erosion_ui::map. Give the control a height or a flexible parent. Keep pin IDs stable and increment recenter to move the camera explicitly. Bind .on_map_idle(...) for center and zoom or .on_map_heading(...) to follow rotation. A selected pin produces HostEvent::Pick.
    Open directions Operation::Directions { point } opens the platform maps handler. Android tries a navigation intent, then a maps directions URL.
    Check access Operation::Permission { feature: Permission::Microphone }; Camera and Location are also supported. Operation::OpenSettings opens the app's OS settings. Android's external camera path checks hardware availability and uses a temporary URI grant.
    Store a small secret Operation::SecretSet { key, value, protected: true }, SecretGet { key }, SecretDelete { key }. Read returns Outcome::Text. A protected read requires the OS to authorize the key operation. Use protected: false for an ordinary app-private secret.
    Verify identity Gallery uses Operation::VerifyDeviceOwner for a system biometric or screen-lock prompt (screen lock on Android 9). A device without a secure screen lock reports SetupRequired. Operation::Authenticate requests biometrics specifically. Protected storage independently enforces read access.
    Clipboard and haptics ClipboardWrite { text }, ClipboardRead, Haptic { feedback: Feedback::Selection }. Trigger clipboard reads from an explicit paste action. Haptics also accept Success, Warning, and Firm. Gallery uses Firm for one stronger tap.

    AssetRef contains a private identifier, display name and MIME type. Persist it alongside the note. Bytes remain in the app container. The file adapters stage writes, move completed files into place, and clean abandoned staging files on a fresh process. An in-process Android Activity recreation can resume a pending file picker. An interrupted capture after process death can be retried. Shares give the recipient temporary read access. The imported files and notebook are local to this app installation.

    Verification¶

    Use the commands in the repository’s sample guide (samples/README.md). Exercise clipboard and storage round trips in Controls Gallery. Check tactile feedback and device authentication on a physical phone.
